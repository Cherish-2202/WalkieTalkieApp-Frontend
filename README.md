# WalkieTalkieApp-Frontend

Premium tactile Walkie-Talkie web UI and prototype with:
- **Retro Telescopic Steel/Black Antenna Roller Wheel**: 5mm thick rotary cylinder with 3D serrated knurl physics, continuous horizontal roll, and 1-step ratchet detent.
- **Glowing Amber Mode Indicator**: Dynamic curved popup badge tethered to the antenna with organic physical sway physics and mode switching (Internet, Bluetooth, Wi-Fi Direct).
- **Physical Hardware Walkie-Talkie Chassis**: Tactile 6-button matrix, amber OLED/LCD display panel with real-time mic equalizer bars, volume/output routing, and hardware scroll wheels.
- **Expressive Push-to-Talk (PTT)**: Centerpiece PTT button with breathing rings, radial ripple waves, and tactile compression states.

## Tech Stack
- React 18 + TypeScript
- Vite
- Tailwind CSS + Framer Motion
- Lucide Icons

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```
